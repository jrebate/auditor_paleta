# Auditor de paleta

Pega los tokens de color de tu sistema de diseño (JSON, variables CSS o Sass, enlaces de Coolors o listas de hex) y comprueba el contraste de todos los pares de texto y fondo a la vez, con WCAG 2.2 y APCA.

Web: https://jrebate.github.io/auditor_paleta/

- Todo se calcula en el navegador; los colores no salen de él.
- Analítica sin cookies con GoatCounter.
- Los resultados son orientativos y no certifican la accesibilidad de un diseño.
